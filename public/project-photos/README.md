# DJAGO project photos

Place approved project photography here before publishing it on the site. Use web-optimised `.webp` or `.jpg` files, ideally at least 1600px wide and under 500 KB where possible.

Suggested naming:

- `ridge-penthouse-01.webp`
- `ridge-penthouse-before.webp`
- `ridge-penthouse-after.webp`
- `team-rockson-djago.webp`

After adding a file, replace the relevant `image`, `beforeImage`, or `afterImage` value in `src/data/content.ts` with `/project-photos/your-file.webp`. Only use photos that DJAGO owns or has permission to publish.
